# Jelly Stack

Playable physics stacking game — drop soft jelly blocks and build a stable tower without toppling it.

Open `index.html` in a browser to play. No build step or server needed. The `assets/matter.min.js` file is included so the game works offline.

Built with JavaScript and Matter.js physics, with soft-body-style stacking, scoring, and game-over / restart state.
