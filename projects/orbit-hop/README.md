# Orbit Hop

Playable browser game — hop between orbits, dodge hazards, and chase a high score.

Open `index.html` in a browser to play. No build step or server needed.

Built with JavaScript and HTML5 Canvas, with a game loop, orbit physics, and score / state handling. A Facebook Instant Games build also exists; the copy here runs in a normal browser, and the Facebook SDK script in it is inert outside Facebook.

Part of James Thao's portfolio projects — see the main [README](../../README.md).
